How the decision is made

Measured evidence

Support and resistance zones with touch counts, RSI, MACD, candle pattern, one-minute structure, volume ratio and ATR — computed from live bars.

A fixed calculation

The evidence goes through a linear model over the signals listed below. Same arithmetic for every symbol, every pass — no discretion, nothing learned between runs.

Enter — or refuse

Out comes a win probability, an expected value and a verdict. A good score can still be refused by a regime filter, and that refusal is published with the rule that fired.

What the engine looks at, in order of weight

Ranked live from the scoring module on every page load, so the order cannot drift from the code. Each one is scored 0–1 where 0.5 is neutral; the ones nearer the top move the win probability further when they agree.

    Two things worth being plain about. The scoring is deterministic technical analysis with a hand-weighted linear model — arithmetic, not a language model, and not something that learns; the AI here is the assistant. And the sizes are quoted in R, the trade’s own risk: 1 R is what you would lose if the stop hit, so an expected value of 0.80 R is about $80 for every $100 put at risk.

    Ask it about any of this

    The assistant is the part of Unisona that genuinely is AI — a language model wired to the same market tools the engine uses. Ask what the current read on a symbol is and it calls the tool, shows you the call, and answers from the result rather than from memory. Every answer names the model that produced it.
