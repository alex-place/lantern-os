How the decision is made

Measured evidence

Support and resistance zones with touch counts, RSI, MACD, candle pattern, one-minute structure, volume ratio and ATR — computed from live bars.

A fixed calculation

The evidence goes through a linear model with published weights. Same arithmetic for every symbol, every pass — no discretion, nothing learned between runs.

Enter — or refuse

Out comes a win probability, an expected value in R and a verdict. A good score can still be refused by a regime filter, and that refusal is published with the rule that fired.

Ask it about any of this

The assistant is the part of Unisona that genuinely is AI — a language model wired to the same market tools the engine uses. Ask what the current read on a symbol is and it calls the tool, shows you the call, and answers from the result rather than from memory. Every answer names the model that produced it.

Where the line sits

The assistant reads the engine and explains it. It does not score the setups and it does not place trades — the two are deliberately separate, so a model having a bad day cannot move a number the engine computed.
