- **The Stripe install scripts now set the webhook signing secret too.** `STRIPE_SECRET_KEY` alone turns the Subscribe buttons on, but `/api/billing/webhook` returns 503 without `STRIPE_WEBHOOK_SECRET` — and that webhook is the source of truth for entitlements, so a customer could complete checkout, be charged, and never receive the tier they paid for. Both scripts now refuse to install a half-configured billing setup unless you explicitly opt out.
