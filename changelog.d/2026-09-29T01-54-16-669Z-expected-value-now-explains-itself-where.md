### Changed

- Expected value now explains itself where it is shown. 0.78 R is trader shorthand that means nothing to most readers, so the hero meter and the accepted-signals list each carry one line saying R is the trade's own risk — what you would lose if the stop hit — and restating the figure as money per $100 risked. The dollar amount is derived from the live number, so it can never drift from the value beside it.
