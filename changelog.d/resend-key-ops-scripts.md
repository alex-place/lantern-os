- **Mail config can be installed on prod without pasting a heredoc** — `ops/gce/Push-ResendKey.ps1` (workstation) and `ops/gce/set-resend-key.sh` (on the VM) install `RESEND_API_KEY` + `MAIL_FROM` + `PUBLIC_BASE_URL`, mirroring the Stripe pair: the key never enters a command line, the drop-in is written `0600` root-owned, and the script verifies the mailer actually came up rather than assuming the restart worked. Until a key is installed, public signups are auto-admitted without proving email ownership (#2065), so this closes a real gap rather than being convenience tooling.
