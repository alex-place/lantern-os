- **Stale quotes no longer permanently deform live candles / inflate ATR (#3014)** — `_tickLastBar()` in `stock-trader.html` spliced every live quote into the forming bar with an unbounded monotonic `high`/`low` that never recovered and was persisted to `localStorage`, so a single stale re-emitted price (watchlist-prices occasionally re-sends a past quote) left a physically-impossible wick that survived reloads — audited SPY 5m bars carried $44–52 (≈6–7%) spikes that inflated the regime engine's ATR ~3.4×. A `_plausibleTick()` guard now drops a tick that jumps more than 5% (circuit-breaker / LULD-halt territory) from the nearer of the bar's open/close, at both the in-bar and boundary-open paths; it fails open when no anchor exists, so it can only remove bad ticks, never invent behavior. Display/indicator only — never touches order execution, and the next real server bar re-anchors truth. Unit-tested against the issue's audited bad ticks (`live-candle-tick-guard.test.js`). The deeper cause — the price feed re-emitting stale quotes — is a separate server-side follow-up.
