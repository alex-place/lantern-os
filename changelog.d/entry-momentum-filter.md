### Added
- **Falling-knife entry filter (auto-trader).** The autopilot buys mean-reversion dips (support / oversold RSI) — right in theory, but it caught knives when down-momentum was still accelerating. Before opening a long it now checks the momentum-timeframe (5m) MACD histogram and **vetoes the entry while the histogram is negative AND still deepening** ("momentum still cratering"), waiting for the histogram to turn up (decelerate) — even if still negative — before buying the dip. Complements, not replaces, the existing S/R + RSI + pattern + EV gate; a rising histogram passes. On by default, `TRADER_ENTRY_KNIFE_FILTER=0` to disable. Fail-open on thin data (never blocks on missing bars). Batched one-fetch per scan; skip reason logged as `falling_knife`. Tests: `test/auto-trader-trailing.test.js`.
