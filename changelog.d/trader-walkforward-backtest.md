### Added
- **Walk-forward backtest for the stock autopilot (Verify).** `experiments/trader_walkforward.js` drives the REAL signal engine (`deriveDirection` / `rileyGate` / `convergenceVerdict`) and the REAL exit logic (protective stop, ratcheting trail, momentum-death, signal-flip) bar-by-bar over historical 15m bars with **no look-ahead** — at bar t only bars[0..t] are visible, entries fill at t+1 open, longs-only, 0.10% round-trip cost. Runs two configs (falling-knife filter off vs on) so the filter's effect is measured, and writes `data/trader-walkforward.json` (equity curve + win rate / avg-R / profit factor / risk-exit win / max-DD / annualized Sharpe). First run over Jun 18–Jul 17 2026 (20 trading days, 16 names): **as-is −94.3% / PF 0.73 / Sharpe −21**, knife-filter −91.3% (marginally better, −23% trades) — the edge, as tuned over this window, is negative; stop-out churn is the leak. Honest limitations documented in the header (news/earnings/sector anchors neutral, single 15m timeframe, ~30-day window).
