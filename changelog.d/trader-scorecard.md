### Added
- **Realized-edge scorecard for the stock autopilot (Verify).** `lib/trader-scorecard.js` + `GET /api/trading/scorecard` turn the autopilot's exit log into honest metrics — win rate, expectancy, profit factor, per-exit-reason breakdown — so an exit/entry change can be judged on realized P&L instead of vibes. Two views: **confirmed** (broker-accepted fills — booked) vs **all** (every exit decision, incl. `needs_confirmation`/`dry_run`). Crucially it reports a **risk-exit win rate** that EXCLUDES the profit-taking exits (`momentum_died`/`take_profit`), which only ever close winners by construction (a ~100% win rate that is a selection artifact, not skill) — so the headline can't be misread. Tests: `test/trader-scorecard.test.js`.
