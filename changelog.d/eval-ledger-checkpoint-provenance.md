- **Eval-ledger `served_checkpoint` no longer collapses every adapter to `@final`** — `checkpoint_id()` built the id from the adapter dir's *basename*, but every training run names its final checkpoint dir `final` (or `best`/`last`), so `ouro-sigma0-adapters/final` and `ouro-distill/<tag>/final` both stamped `<model>@final`. The ledger literally could not tell which adapter produced a HumanEval row — the provenance the docstring promises was defeated for the one universal naming convention. Generic leaf names are now qualified with their run dir (`@ouro-sigma0-adapters-final`, `@lr5e5-r16-final`); unique names like `checkpoint-600` pass through unchanged, and Windows/`\`-separated paths resolve identically to POSIX on Linux CI. This directly serves #2766 ("the most important benchmark is rarely run" — and when it is, mislabeled). Regression-guarded in `tests/test_eval_ledger.py`.
