- verify(#2872): **M1 No-Free-Confidence is now an ENFORCED runtime gate**, not just a replay audit. New `lib/m1-gate.js` mirrors `experiments/v1_10_toy/m1_ledger_check.py` exactly (same claim normalization + evidence fingerprint, so replay and live enforcement can never disagree) and is wired into every JS ledger write path — `convergence-records.js` (hypothesis rows) and both `dream-chat.js` append sites (claim batches + the command/verify helper). Same-batch pairs are gated via an in-process tail; cross-process writes are picked up by mtime. 9 zero-dep tests in `test/m1-gate.test.js`.
