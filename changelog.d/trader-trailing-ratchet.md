### Fixed
- **Trailing stop no longer resets on restart, and now ratchets tighter for big winners (auto-trader).** The high-water mark (`_peak`) and per-symbol timers were in-memory only, so every server restart reset each position's peak to its price at boot — the trailing stop then measured from a lower peak and let a winner give back a full leg before firing (the SOXS "+35% peak → gave back ~$3k, never exited" case, on a box that had been restarted repeatedly). State now persists to `data/lantern-garage/trading/trader-state.json` (snapshot each scan, reload at boot). The trailing distance also **ratchets**: base 2.5% (was a flat 3%), tightening to 2.25% / 1.75% / 1.25% as the peak gain crosses 6% / 12% / 25% — so a +35% winner locks in ~1.25% off its high instead of round-tripping 3%+. Base stays `TRADER_TRAIL_PCT`-tunable; a tighter base always wins over the ratchet. Tests: `test/auto-trader-trailing.test.js`.
