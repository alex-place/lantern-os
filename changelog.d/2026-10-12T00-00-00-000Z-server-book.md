### Fixed

- trader: a user without a broker of their own is no longer answered from the server's brokerage session. Five reads fell back to the server's own IBKR session — the operator's book wherever its gateway is signed in — when a user's broker did not answer: positions, orders (and the server-wide manual ledger), portfolio history (and the server's session rows), /status, and the public zones feed's per-ticker position. Only an admin or the operator profile reads that book now. Everyone else is told what is true: 'no broker connected' (the trader page now says so, with a link to Settings, instead of a STALE badge and 'the broker could not be reached'), or 'your broker did not answer' for someone who has one.
