### Fixed

- trader: **the chart is no longer the narrowest thing on the screen.** The desk's side panels are fixed-width (chat 360 + order ticket 320 + watchlist 320, plus 88px of rails), so 1088px of any viewport is spoken for before the chart gets a pixel. On a 1920px monitor that still leaves it 832px — but measured in a browser on the two commonest laptop widths it left the chart **352px at 1440** (narrower than the chat panel beside it) and **192px at 1280**, where the candles stop being readable at all. A trading desk whose chart loses to its chat sidebar has its priorities inverted. The chat dock's *first-visit* default is now viewport-aware: below 1500px it starts closed and the chart keeps ~550px (measured 552px at 1280, a canvas of 498px versus 138px before). This is a default, not a lockout — an explicit choice is persisted and wins in both directions, and nothing changes on the large screens the layout was designed for.

### Changed

- ci: **300 test files that had never run once are now enforced.** `apps/lantern-garage/test/` held 305 suites; CI ran **five**, named one by one in workflow YAML. The rest were not skipped or disabled — nothing referenced them, so nobody noticed. That included every suite written for the 1.15.4 trader work (`alert-engine`, `mfe-mae`, `track-record`, `scorecard-breakdown`, `chat-trader-tools`, `ledger-attribution`): written, passing locally, and invisible to the pipeline meant to protect them. A hand-maintained list guarantees this outcome — it is correct the day it is written and every test added later is dark by default. `scripts/run-garage-tests.mjs` now globs the directory, so a new test is protected the moment it lands. 279 of the 305 passed on the day this landed and are enforced; the 26 that did not are listed in `apps/lantern-garage/test/.quarantine` with a **ratchet** — a quarantined test that starts passing fails the build until its line is deleted, so the list can only shrink.

### Added

- trader: a guard on the feed-glitch **wick sanitizer**, which was load-bearing and untested. The keyless feed ships intraday bars with tiny bodies and monstrous one-sided wicks from stale pre/after-hours quotes; measured live against our own API at 1h on 2026-08-18, 7.3% of SPY bars exceed 4× the median span, GLD 9.9%, with tails that are not typos (SOXS 3332×, TZA 728×). `stock-trader.html` clamps them in **two** places that must agree — the drawn candle and the auto-range — and if only one is fixed the result is worse than no fix: the range is set from a bogus extreme while the candles render sane. The new test evaluates the *shipped* expression rather than a copy of it, pins the 4× threshold, the body ± one-median clamp, the intraday-only rule (a >4× wick on a daily can be a real crash day), the strict boundary case, and the disabled-when-no-median guard. Mutation-checked: reintroducing the drift, or moving the threshold, turns it red.
