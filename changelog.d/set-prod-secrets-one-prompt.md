- **One script to set every prod secret** — `ops/gce/Set-ProdSecrets.ps1` prompts for the Stripe key, Stripe webhook secret and Resend key (input hidden), installs each as a root-owned `0600` systemd drop-in, restarts once, and verifies both services actually came up. Removes the `setx` + open-a-new-shell round trip, and nothing is written to your environment or echoed to the terminal.
