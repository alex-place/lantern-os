### Fixed

- trader: **signal exits cancel the resting stop before placing the sell — a stop-protected position can actually leave the book now.** The signal-exit path placed the market sell first and canceled the protective stop second; on Alpaca the stop reserves the full position quantity, so the sell was rejected every time, the engine waited its 8-minute reattempt, re-protected, and repeated — observed live 2026-09-18 as four canceled TLT orders, an `exit_frozen` freeze, and a position that had been trying to leave since its bearish signal confirmed (#3660, finding A). The pair is now in the order `cancelRestingStops` was built for — it already settles, waiting until the broker releases the reserved shares (#3407) — so the sell arrives against freed quantity. And the failure is never silent again (finding B): the `exit_intent` ledger row now carries the broker's rejection text in `error`, and a placement failure logs a warn line. The frozen position needs no manual repair — the unclosable freeze already allows one clean retry cycle per `TRADER_UNCLOSABLE_RETRY_MIN` (default 60 min), which now succeeds.
