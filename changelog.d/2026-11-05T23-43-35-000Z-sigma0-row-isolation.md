### Fixed

- sigma0: three gaps that #3814's independent review found, all older than it, now hold per trajectory, plus two from its post-merge review and three from a review of this fix. A float64 model with the anti-collapse operator attached no longer raises in the kick: `rollout` drew float32 noise in every dtype, and it now casts that draw to the state's dtype, so every float32 run and every float64 run that never reached the kick is unchanged bit for bit, and replay from `base_seed` holds. A direct caller of `forward_step` that passes float32 noise to a float64 model works too. One trajectory whose Jacobian or covariance holds a NaN or inf no longer fails the batch. Its four gate signals read NaN, so it never fires, where an inf Jacobian, or a finite one whose singular values overflow, used to read as rank 0 (collapsed) and fire. Neither a surprise spook nor a batch-wide proximity can select it, no batched SVD or eigendecomposition sees it, and its covariance passes through unprojected. A row whose covariance step overflows from finite inputs is blocked, with a receipt saying so, instead of failing the kick for every row. An operator asked directly to act on a broken row refuses, naming it. A hot-swap is now accepted only if every probe trajectory's own relative drift change is below `tol`: one batch norm let a candidate that flips one trajectory's drift pass on the others. A one-trajectory swap is decided as before, a float16 probe with a still row no longer divides by zero, an empty probe is decided as before, and `SwapRecord` keeps each row's delta (`row_deltas`, `worst_row`). A covariance given once for the batch, `(1, d, d)` or `(d, d)`, no longer crashes the receipts of rows past the first. And "a batch run equals its rows run alone, bit for bit" now says what is true: the operators' decisions are each row's own, but in numbers a batched run agrees with its rows alone only to rounding, since `Tensor.std` and the neural node's matrix products round a lone row differently, so a row within rounding of a threshold can decide differently. An attached surprise monitor still factors all rows in one batched Cholesky. See §3 and Appendix C of `docs/SIGMA0-COLLAPSE-CERTIFICATE.md`.
