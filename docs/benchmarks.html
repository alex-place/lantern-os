Whole-loop verdict

The Act stage is genuinely strong and honestly measured this snapshot — Qwen2.5-Coder at 0.829 full-HumanEval, with the 0.72 → 0.829 correction being the harness catching up to reality, not inflation. And the loop's differentiating stage, Act + Verify (SWE-bench), now has its first real number on master: 0/5 resolved — humbling, but honest, and no longer a blank.

0% is the measured single-shot floor, exactly where the published curve puts an affordable-n run for a stack this size — so it isn't a regression, it's a baseline. The loop is stronger as a system this snapshot because the empty cell that mattered most is now filled; the next lever is the agentic propose → test → retry loop, the only SWE-bench configuration with real dynamic range at our rung.

Competitor rows were re-validated live on Jul 17 (our own numbers unchanged — no eval run since Jul 8). The podiums barely moved, but the cross-check found the rivals' numbers are softer than they look: HumanEval's live board has gone stale — the flagships stopped self-reporting, so an OSS model tops it and a 2024 Claude sits at #3; the 98%+ honesty-detection SOTA is largely a teacher-forced artifact (PARALLAX: top probes fall to 0.62 on live text, at our own canary's level); and the memory podium is vendor self-reports under clashing protocols (one 93% claim collapses to 32% standardized). External reality cuts both ways — it right-sizes the frontier as much as us.
